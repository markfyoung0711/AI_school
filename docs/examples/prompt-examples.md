# Practical Prompt Examples

This guide provides concrete examples of prompts you can use to explore AI capabilities.

## Learning and Education

### Understanding Concepts
```
"Explain [concept] as if I'm a [beginner/student/professional]"
Example: "Explain machine learning as if I'm a 10-year-old"
```

### Step-by-Step Learning
```
"Break down how to [task] into simple steps"
Example: "Break down how to write a Python web scraper into simple steps"
```

### Analogies and Comparisons
```
"Compare [concept A] and [concept B], highlighting the key differences"
Example: "Compare supervised learning and unsupervised learning, highlighting the key differences"
```

## Coding Assistance

### Code Generation
```
"Write a [language] function that [does something]"
Example: "Write a Python function that finds the longest palindrome in a string"
```

### Code Explanation
```
"Explain what this code does line by line: [paste code]"
```

### Debugging Help
```
"I'm getting this error: [error message]. Here's my code: [paste code]. What's wrong?"
```

### Code Review
```
"Review this code for best practices and suggest improvements: [paste code]"
```

## Creative Tasks

### Brainstorming
```
"Generate 10 creative ideas for [project/topic]"
Example: "Generate 10 creative ideas for a mobile app that helps students study"
```

### Writing Assistance
```
"Write a [type] about [topic] in [style]"
Example: "Write a professional email about requesting time off in a polite but firm tone"
```

### Story Development
```
"Create a story outline about [premise] with [elements]"
Example: "Create a story outline about a detective solving a mystery in a cyberpunk city"
```

## Problem Solving

### Analysis
```
"Analyze the pros and cons of [decision/approach]"
Example: "Analyze the pros and cons of using a microservices architecture"
```

### Strategy Development
```
"What's the best approach to [challenge]? Consider [constraints]"
Example: "What's the best approach to learning web development? Consider I have 3 months and work full-time"
```

### Troubleshooting
```
"I'm trying to [goal] but [problem]. What should I try?"
Example: "I'm trying to deploy my app to AWS but getting timeout errors. What should I try?"
```

## Information Gathering

### Research
```
"Summarize the key points about [topic]"
Example: "Summarize the key points about quantum computing"
```

### Comparisons
```
"Create a comparison table of [options] based on [criteria]"
Example: "Create a comparison table of React, Vue, and Angular based on performance, learning curve, and community support"
```

### Current Understanding Check
```
"What are the latest developments in [field] as of [date]?"
Note: AI has a knowledge cutoff date, so it will tell you if information is beyond that date.
```

## Prompt Engineering Tips

### 1. Be Specific
- ❌ "Tell me about dogs"
- ✅ "What are the top 5 dog breeds for apartment living and why?"

### 2. Provide Context
- ❌ "How do I fix this?"
- ✅ "I'm building a React app and getting a 'Cannot read property of undefined' error in my useEffect hook. Here's my code: [code]"

### 3. Specify Format
- ❌ "Tell me about programming languages"
- ✅ "List 5 programming languages with their primary use cases in a bullet point format"

### 4. Set Constraints
- ❌ "Write code to sort an array"
- ✅ "Write a Python function to sort an array using bubble sort. Include comments explaining each step."

### 5. Request Examples
- ❌ "Explain recursion"
- ✅ "Explain recursion with a simple code example in JavaScript"

### 6. Iterative Refinement
If the first response isn't quite right:
- "Can you make that simpler?"
- "Can you provide more technical details?"
- "Can you show an example of that?"
- "Can you focus specifically on [aspect]?"

## Advanced Prompting Techniques

### Chain of Thought
Ask the AI to think step-by-step:
```
"Let's solve this step by step: [problem]"
```

### Role Playing
Ask the AI to take on a specific role:
```
"Act as a [role] and help me with [task]"
Example: "Act as a senior software engineer and review my code architecture"
```

### Multi-Part Tasks
Break complex tasks into parts:
```
"First, [task 1]. Then, [task 2]. Finally, [task 3]."
Example: "First, explain what APIs are. Then, show me how to call an API in Python. Finally, give me a real-world example."
```

## Practice Exercises

Try these prompts yourself:

1. **Learning**: "Explain how the internet works using a simple analogy"
2. **Coding**: "Write a Python script that reads a CSV file and calculates the average of a numeric column"
3. **Creative**: "Generate 5 unique names for a tech startup focused on sustainable energy"
4. **Problem Solving**: "I want to start a blog but don't know where to begin. Give me a step-by-step plan"
5. **Analysis**: "What are the main differences between AI, machine learning, and deep learning?"

## Experimenting with Prompts

The best way to learn is by trying different approaches:
- Start with a basic prompt
- Refine based on the response
- Try different phrasings
- Add or remove context
- Adjust the level of detail

Remember: AI is a tool, and like any tool, you get better with practice!
