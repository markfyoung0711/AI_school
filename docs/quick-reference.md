# Quick Reference Guide

A one-page reference for working with AI effectively.

## 🎯 The 5 Keys to Effective Prompts

1. **Be Specific** - Say exactly what you want
2. **Provide Context** - Give relevant background information
3. **Set Constraints** - Specify format, length, style, etc.
4. **Request Examples** - Ask for concrete demonstrations
5. **Iterate** - Refine your prompt based on responses

## 📝 Prompt Template

```
[Role/Context]: I'm a [your background]
[Task]: I need help with [specific task]
[Constraints]: Please [format/style requirements]
[Additional]: [Any other relevant details]
```

Example:
```
I'm a beginner Python programmer learning web development.
I need help creating a function that validates email addresses.
Please include comments explaining each part and handle common edge cases.
Also show me how to test this function.
```

## 🔄 The Iterative Process

```
1. Start with a clear prompt
2. Review the response
3. Identify what's missing or wrong
4. Refine your prompt
5. Repeat until satisfied
```

## 🧰 Essential Prompts

### For Learning
- "Explain [concept] in simple terms"
- "What's the difference between [A] and [B]?"
- "Give me an example of [concept]"
- "Break down [process] into steps"

### For Coding
- "Write a [language] function that [does X]"
- "Debug this code: [paste code]"
- "Explain what this does: [paste code]"
- "Optimize this code: [paste code]"

### For Writing
- "Write a [type] about [topic]"
- "Improve this paragraph: [text]"
- "Summarize this text: [text]"
- "Brainstorm ideas for [project]"

### For Problem Solving
- "What are pros and cons of [option]?"
- "How do I [solve problem]?"
- "What's the best approach to [challenge]?"
- "Compare [option A] vs [option B]"

## 🚫 Common Mistakes to Avoid

1. ❌ Being too vague: "Tell me about programming"
   ✅ Being specific: "Explain the difference between compiled and interpreted languages"

2. ❌ No context: "Fix this"
   ✅ With context: "I'm getting a TypeError in this Python function: [code]. What's wrong?"

3. ❌ Expecting perfection: Accepting first response without iteration
   ✅ Iterating: "Can you make that more concise?" or "Add more examples"

4. ❌ Asking for real-time data: "What's the current stock price?"
   ✅ Appropriate use: "Explain how stock prices are determined"

## 📊 Understanding AI Limits

### AI Can:
- ✅ Answer questions on many topics
- ✅ Write and explain code
- ✅ Generate creative content
- ✅ Analyze and summarize text
- ✅ Provide step-by-step guidance

### AI Cannot:
- ❌ Access real-time information
- ❌ Browse the internet (usually)
- ❌ Remember previous conversations (depends on system)
- ❌ Guarantee 100% accuracy
- ❌ Replace professional advice (medical, legal, etc.)

## 💡 Quick Tips

1. **Start Simple**: Begin with straightforward questions
2. **Add Detail Gradually**: Refine based on responses
3. **Use Examples**: Show what you want
4. **Ask for Alternatives**: "Give me 3 different approaches"
5. **Request Explanations**: "Explain your reasoning"
6. **Check Work**: Verify important information
7. **Break Down Complex Tasks**: Split into smaller steps
8. **Save Good Prompts**: Reuse what works

## 🔍 When Things Go Wrong

### AI Doesn't Understand
→ Rephrase your prompt with more context

### Response Too Generic
→ Add specific constraints and examples

### Response Too Complex
→ Ask for simpler explanation: "Explain this as if I'm a beginner"

### Incorrect Information
→ Ask for sources or verify independently

### Not What You Wanted
→ Clarify: "I meant [X], not [Y]"

## 📚 Key Terms (Quick Reference)

- **Prompt**: Your input/instruction to AI
- **Token**: Basic unit of text (~3-4 chars on average in English; varies by language)
- **Context**: Information AI has access to
- **Hallucination**: AI making up false information
- **Temperature**: Controls randomness (low = focused, high = creative)
- **RLHF**: How AI learns from human feedback
